# 🎓 Student Internship Portal

A modern and responsive internship portal where students can explore internship opportunities, view detailed information, apply for internships, save opportunities, and track their applications.

## 🚀 Features

* 🔍 Internship search
* 🎯 Category, location, work-type and stipend filters
* 📋 Detailed internship information
* 📝 Internship application form
* 📊 Application tracking dashboard
* ❤️ Save/favorite internships
* 👤 Student profile management
* 📄 Resume upload interface
* 🔔 Notifications
* 🌙 Dark/Light mode
* 💾 LocalStorage data persistence
* 📱 Fully responsive design
* ⏰ Internship deadline tracking
* 🔔 Toast notifications

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* LocalStorage

## 🎯 Objective

The objective of this project is to provide students with a simple platform to discover relevant internships, submit applications, save opportunities, and monitor their application progress.
